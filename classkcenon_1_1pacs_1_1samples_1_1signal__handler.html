void kcenon::pacs::samples::signal_handler::install ( shutdown_callback callback = nullptr)
static

Install signal handlers with optional callback.

Parameters
callbackFunction to call when shutdown signal is received

Installs handlers for SIGINT and SIGTERM (POSIX) or SIGINT and SIGBREAK (Windows). The callback is invoked once when the first signal is received.
