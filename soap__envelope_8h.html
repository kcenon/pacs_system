Detailed Description

SOAP 1.2 envelope builder for IHE XDS.b ITI-41 requests.

Produces a SubmitObjectsRequest body wrapped in an Envelope with a WS-Addressing header and an empty WS-Security header that wss_signer fills in. XML is serialized via pugixml; the output is UTF-8 without a BOM, with XML declaration, suitable for canonicalization.

This is an internal header - not installed, not part of the public API.
