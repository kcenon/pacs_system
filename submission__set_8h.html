Detailed Description

XDS.b submission set metadata for ITI-41 Provide and Register Document Set-b.

These are plain data carriers. They mirror the subset of ebRIM/ebRS attributes required for a minimally conforming XDS.b submission set containing one or more documents. Fields are deliberately string-typed because the upstream DICOM dataset and the downstream ebXML registry both canonicalize to strings.

See also
IHE ITI TF-2a §3.41 - Provide and Register Document Set-b
