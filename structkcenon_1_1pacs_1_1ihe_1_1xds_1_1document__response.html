Detailed Description

ITI-43 RetrieveDocumentSet response payload.

mime_type is echoed from the MTOM part's Content-Type header. content holds the retrieved document bytes decoded from the multipart/related attachment. registry_response_status is the ebRS status echoed from the response envelope; document_consumer::retrieve already maps non-Success to a typed error, so receiving a document_response implies the registry reported Success.
