Detailed Description

Parser for IHE XDS.b ITI-18 AdhocQueryResponse.

Locates the query:AdhocQueryResponse body in the signed SOAP envelope emitted by the Document Registry, reads its status attribute, and walks the ExtrinsicObject entries in the embedded RegistryObjectList into a registry_query_result.

This is an internal header.
