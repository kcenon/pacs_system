Detailed Description

Typed error codes for IHE XDS.b actors (ITI-41 and siblings)

Every public API in kcenon::pacs::ihe::xds returns kcenon::common::Result<T>. Error codes here are the numeric tag passed to make_error so callers can branch on failure class without parsing strings.
